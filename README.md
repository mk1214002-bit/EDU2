# 국방예산 대시보드

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 인터넷 연결이나 별도 설치가 필요 없습니다.

- 부문과 회계구분 필터가 모든 지표와 8개 그래프, 상세 표에 적용됩니다.
- 회계구분 목록은 선택한 부문에 맞게 바뀝니다.
- 상세 표에서는 프로그램/구분 검색, 열 제목 정렬, 필터 결과 CSV 다운로드를 사용할 수 있습니다. 검색은 상세 표에만 적용됩니다.
- 그래프에 마우스를 올리면 원 단위가 아닌 **억 원 단위** 상세 금액이 표시됩니다.
- 내부거래·보전지출 및 내부거래 차감액을 포함합니다. 양수 기준 그래프에는 차감액을 포함하지 않습니다.

## 파일

- `index.html`: 대시보드 화면
- `styles.css`: 반응형 디자인
- `app.js`: 필터·집계·그래프·표 로직
- `data.js`: `프로그램별_재원.xlsx`에서 추출한 32개 행의 데이터 스냅샷

원본 엑셀을 변경해도 이 대시보드의 데이터는 자동 갱신되지 않습니다.
전체 프로그램 금액 합계는 2026년 677,039억 원, 2027년 732,776억 원이며 PDF 총재원 표와 각각 1억 원 차이가 있습니다. 원자료를 임의 조정하지 않았습니다. 증감률은 엑셀의 금액을 기준으로 다시 계산합니다.
